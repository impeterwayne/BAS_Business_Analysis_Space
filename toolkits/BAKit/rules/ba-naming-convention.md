# BA Naming Convention

All output files generated by agents MUST follow these conventions.

## Versioned deliverables

```
[ID]_[feature-name]_[type]_[YYYYMMDD]_v[N].[ext]
```

| Component | Format | Example | Notes |
| :--- | :--- | :--- | :--- |
| `ID` | `UC-XXX`, or `{app-slug}` for competitor docs, `{feature-slug}` for Figma analyses and Product Decision Summaries, or `{topic}` for comparisons | `UC-101`, `momo`, `ewallet` | Use Case ID from the requirement document when one exists |
| `feature-name` | lowercase-kebab, max 3–4 words | `user-login` | Omit for competitor docs, Figma analyses and decision summaries (the slug already names them) |
| `type` | see table below | `extracted` | |
| `YYYYMMDD` | date the file was created | `20260927` | |
| `v[N]` | version number | `v1` | Never reuse a number |

## Output types

| Type | Suffix | Extension | Written by |
| :--- | :--- | :--- | :--- |
| Extracted requirement | `extracted` | `.md` | `document-extraction` |
| Audited requirement | `audited` | `.md` | `BA-audit-SRS` |
| Question backlog | `question-backlog` | `.md` | `BA-audit-QnA` |
| Feature brief | `brief` | `.md` | `brainstorm-features`, `ba-templates` |
| Product Decision Summary | `decisions` | `.md` | `product-decision` |
| User stories | `stories` | `.md` | `ba-templates` |
| Competitor app profile | `profile` | `.md` | `competitor-app-analysis` |
| Competitor screen inventory | `screens` | `.md` | `competitor-app-analysis` |
| Competitor flow analysis | `flow-{flow}` | `.md` | `competitor-app-analysis` |
| Feature comparison & gap | `comparison` | `.md` | `competitor-app-analysis` |
| Feature checklist | `checklist` | `.md` | `apk-feature-extractor` |
| Figma design analysis | `figma` | `.md` | `figma-ba-analysis` |

## Evidence files (competitor screens)

```
docs/BA/competitor/{app-slug}/screens/{flow}-{NN}-{slug}.png
docs/BA/competitor/{app-slug}/screens/{flow}-{NN}-{slug}.tree.txt
```

`NN` is the visit order within the flow (`01`, `02`, …). Screenshot and tree share the same stem.

## Evidence files (Figma reference images)

```
docs/BA/figma/{feature-slug}/screens/{NN}-{slug}.png
docs/BA/figma/{feature-slug}/screens/{NN}-{slug}-{state}.png
```

`NN` matches the screen number in the analysis's Screen Inventory.

## Living specs (not versioned by file name)

| Document | Path |
| :--- | :--- |
| SRS | `docs/project-srs.md` |
| FSD (legacy, only where a project already uses it) | `docs/project-fsd.md` |
| Use case | `docs/usecases/{module}/uc-{module}-{nnn}-{slug}.md` |
| Diagram source (Mermaid) | `docs/diagrams/{module}/{diagram-id}.md` |
| Test cases | `docs/testcases/{module}/tc-{module}-{nnn}-{slug}.md` |

These are updated in place; the version lives in the header and Change Log.

## ID conventions

| Item | Format | Example |
| :--- | :--- | :--- |
| Functional requirement | `FR-{MOD}-{NNN}` | `FR-AUTH-001` |
| Candidate requirement (from competitor gap) | `FR-CAND-{NNN}` | `FR-CAND-004` |
| Candidate requirement (from a Figma design) | `FR-DSN-{NNN}` | `FR-DSN-002` |
| Candidate business rule (from a Figma design) | `BR-CAND-{NN}` | `BR-CAND-03` |
| Use case | `UC-{MOD}-{NNN}` | `UC-AUTH-001` |
| User story | `US-{MOD}-{NNN}` | `US-AUTH-003` |
| Business rule | `BR-{NNN}` | `BR-012` |
| Product decision | `PD-{NNN}` | `PD-007` |
| Open question (SRS / use case / audit) | `Q-{NNN}` | `Q-012` |
| Audit gap | `AUD-{NNN}` | `AUD-004` |
| User Flow diagram | `UF-{MOD}-{NNN}` | `UF-AUTH-001` |
| Activity diagram | `ACT-{MOD}-{NNN}` | `ACT-AUTH-002` |
| Sequence diagram (conditional) | `SEQ-{MOD}-{NNN}` | `SEQ-PAY-001` |
| Competitor feature | `CF-{NNN}` | `CF-020` |
| Gap | `GAP-{NNN}` | `GAP-007` |

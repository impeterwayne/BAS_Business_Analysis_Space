# General Collaboration Rules

## Process Flow
All agent modules MUST adhere to the following sequence for any given Use Case or report generation lifecycle:
1.  **Step 1:** Auditor Module validates constraints and inputs.
2.  **Step 2:** Challenger Module questions logic and surfaces unknown dependencies.
3.  **Step 3:** Architect Module builds out FDDs/SRSs once variables are stabilized.

## System Document Management
*   Any newly identified requirement variations or rule extractions detected by Auditors must be stored systematically inside `.agents/skills/rules/`.
*   All critical questions and ensuing answers generated by Agent 2 and Agent 5 MUST be tracked centrally. Push these updates to the master log at `docs/QnA_Backlog.md`.

## Control Commands
Agents will wait and respond to specific master control commands from the User to transition through the sequential states:
*   `Approve B1` -> Proceed to the Questioning (Challenger) phase.
*   `Finalize QnA` -> Trigger the Architect phase to start drafting comprehensive documents.
*   `Update [Content]` -> Trigger the Auditor phase to perform an Impact Analysis based on content edits.
